# Проверка MVP

Автотесты: политика локального подтверждения, одноразовый снимок, устаревший снимок, изменение окна во время подтверждения, выход за границы, управляющие символы в тексте, неизвестные команды, соответствие адаптеров.

Ручной прогон для **каждого** слайсера, Windows 100% и 150% DPI, русская и английская локализация:

- Список окон: правильный exe/PID; несколько окон → явный выбор handle.
- Снимок переднего окна: точные размеры/геометрия; viewport и панели видны. Фон/минимизация → отказ.
- Без согласия и при «Нет» никакого ввода.
- После движения/изменения окна → новый снимок; старый digest не работает.
- Переключение фокуса во время подтверждения → отказ, без ввода в другое приложение.
- Импорт тестового STL с пробелами и кириллицей в пути; проверка объекта на столе.
- Выбор объекта, угол 90° в поле поворота, PLA-профиль, поддержки, нарезка и просмотр слоёв.
- Открытие диалога отправки: сверить принтер/пластину, нажать «Нет» в подтверждении и убедиться, что задание не отправлено. Реальную печать запускать только по отдельной явной команде пользователя.
- Закрытие/перезапуск слайсера, появление модального окна, смена профиля и предупреждения → никаких слепых повторов.

Полный прогон не считается выполненным лишь по успешным unit tests. Результаты фактической проверки записываются в docs/validation.md.
